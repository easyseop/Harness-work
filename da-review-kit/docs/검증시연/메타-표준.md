# 메타(표준) — DA검토 하네스 검사 기준값

> ⚠️ 현재 값은 **대표 mock(예시)** — 실제 행내 등록목록으로 교체 시 동일 동작.
> 영문변수명 규칙 = **camelCase, 첫글자 소문자** (고객성별 → `custSex`).

## 1. 테이블 명명규칙
- 패턴: `^T[HS][A-Z]{3}[A-Z]{2}[0-9]{2}$`  =  **T + 시스템(H/S) + 앱(3) + 소그룹(2) + 일련(2)** = 9자
- 시스템구분: `H`=Host DB2, `S`=Server

**어플리케이션코드(3)**
| 코드 | 업무 | 코드 | 업무 |
|---|---|---|---|
| DPS | 수신/예금 | INS | 보험 |

## 2. 컬럼 명명규칙
- 한글명·영문명·인포타입 **필수**, 컬럼은 **인포타입(도메인)으로 끝남**
- 영문변수명 = **camelCase**(첫글자 소문자)
- 한글명 최대 Server 15자 / Host 10자 (30byte)
- 끝자리 숫자: **허용**(조직 결정) — 매칭 시 끝 숫자 무시
- 컬럼 = `[수식어]+[도메인 끝말]`  ·  인포타입 = `도메인+길이`(예 년월일8)

## 5. 구조·관계
- PK(식별자) **필수**
- 권장 감사컬럼: `sysLstPrcDtm`, `sysLstUsrNo` (없으면 경고)
- M:N 직접관계 **금지** (연결엔티티로 분해)

## 6. 표준/비표준 판정 (우선순위)
1. 입력 `table.standard`(true/false) → 2. `schema ∈ standard_schemas` → 3. `default_standard`(기본 true=엄격)

## 7. 인스턴스코드 정의서 규칙
- 업무인스턴스명 끝말: `구분코드` / `코드` / `여부` / `유무`
- `여부`/`유무` 끝말 → 코드값 **0/1만**
- **단독사용금지 12단어**: 자산, 부채, 금액, 연금, 년월일, 여부, 유무, 건수, 명, 시각, 식별자, 현금
- 예약 코드값: `0`=해당무(해당사항없음) · `9`=기타
