## 요약 — 잡는 케이스 총 29종
- **1단계 DB설계**: 물리/테이블명 4(P1~P4) + 컬럼 10(P5~P14) + 구조·관계 5(P15~P19) + 속성 4(A1~A4) = **23**
- **2단계 인스턴스코드**: 명명 6(I1~I6) + 코드값 5(I7~I11) = **11**
- 차단(🔴) 위반·정보부족 즉시 반송 / 경고(🟠) 통과+주의 / 건너뜀(⚪) 검토 제외

> ※ 권고(suggestion)는 **게이트가 결정적으로 직접 출력**합니다(JSON `findings[].suggestion`). 예: `custGender 불일치 → 영문명을 'custSex' 로 변경(camelCase)`.
