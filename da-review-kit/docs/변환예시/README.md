# 변환 예시 (참고용 보관)

자유양식 원본 → INPUT 변환이 어떻게 되는지 보여주는 **초기 예시**입니다.
테스트 입력과 섞이지 않도록 `input/freeform/` 에서 이곳으로 옮겨 보관합니다.

| 원본(자유양식) | 변환 결과(INPUT) |
|---|---|
| `설계도1_자유텍스트.txt` | `설계도1_변환결과.yaml` |
| `설계도2_표형식.md` | `설계도2_변환결과.yaml` |

> 실제 테스트/시연 입력은 `../../input/freeform/` (ddl·text·instance) 를 쓰세요.
