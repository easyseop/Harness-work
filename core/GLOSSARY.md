# 용어풀이

이 문서들에 나오는 용어를 쉬운 말로 한 번만 정의한다. 모르는 단어가 나오면 여기로 돌아오면 된다.

| 용어 | 쉬운 뜻 |
|---|---|
| **하네스** | 개발 과정에 끼어들어, 규칙을 지키게 하고 검사·서류를 자동으로 챙겨 주는 **도구 묶음**. (여기서는 "은행 내부로 안전하게 들여보내기 위한 준비 도구 묶음") |
| **Spine** | 전체 작업 흐름을 **조율하는 중심부**. 직접 일을 처리하지 않고, 필요한 도구(하네스)를 순서대로 부르고 결과를 모으는 역할만 한다. |
| **게이트** | **자동 검사·검문소**. 정해진 조건을 만족하는지 통과/실패로 판정한다. 통과해야 다음 단계로 넘어간다. |
| **명세 파일 (manifest)** | 하네스가 자기를 소개하는 **자기소개 파일**. "나는 어느 단계에서 일하고, 무엇을 검사하고, 무슨 서류를 내놓는다"를 적어 둔다. Spine은 이 파일만 보고 하네스를 부른다. |
| **반입** | 외부망에서 만든 결과물을 **은행 내부망으로 들여오는 것**. |
| **반입 묶음** | 내부로 들여보낼 때 함께 넘기는 **한 보따리**. 소스코드뿐 아니라 검사 기록·서류·목록을 다 담는다. |
| **증거 자료 (증적)** | "이 검사를 했고 통과했다"를 보여 주는 **기록/서류**. 나중에 감사(점검)에서 증명용으로 쓴다. |
| **예외 승인 (waiver)** | 어떤 검사를 부득이 건너뛸 때 받는 **정식 허가**. 기한·승인자·사유가 반드시 있어야 한다. |
| **반입 적합성 증명 (attestation)** | "이 묶음은 들여와도 된다"는 것을 보증하는 **확인서**. |
| **정책 파일 (policy)** | "우리 조직이 허용/금지하는 규칙"을 적어 둔 파일. 예: "자바 21은 허용, AGPL 라이선스는 금지". |
| **분류 결과 (profile)** | 프로젝트 한 건이 "무엇인지"를 정리한 **분류표**. 예: "이건 배치 프로그램, 자바로 만들고, 내부 서버에 올라감". |
| **계약 (contract)** | 내부 시스템과 주고받는 약속을 **민감정보 없이** 정리한 것. 무엇을 넣으면 무엇이 나오는지, 오류는 무엇인지 등. |
| **대역 (mock)** | 진짜 내부 시스템 대신 쓰는 **가짜 대체물**. 외부망에서 시험할 때 진짜 대신 붙인다. |
| **외부망** | 인터넷·외부 자료를 쓸 수 있는 **개발용 망**. 여기서 만든다. |
| **내부망 (행내)** | 은행 안쪽 망. 실제 시스템·고객정보가 있는 곳. 여기로 들여와 확인·배포한다. |
