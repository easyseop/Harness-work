# internal-solution 하네스 매뉴얼 (처음 보는 사람용)

> 모르는 용어는 `core/GLOSSARY.md`(용어풀이)를 함께 보세요.

---

## 1. 이 하네스가 왜 있나 (비유로)

외부망에서 "사내 쪽지로 알림 보내기" 같이 **내부 시스템에 연결해야 하는 기능**을 만들 때가 있습니다.
그런데 외부망에 진짜 쪽지 서버 주소·접속코드를 적으면 내부 비밀이 새는 사고입니다.

비유하자면, **메뉴판만 보고 요리를 연습하는 것**과 같습니다.
주방(내부 시스템)에 직접 들어가지 않고, "이걸 주문하면 이게 나온다"는 **메뉴판(계약)** 과
**모형 음식(대역/Mock)** 으로 연습합니다. 실제 주방 연결은 내부망에 들어가서 붙입니다.

이 하네스는 그 **메뉴판(솔루션 카드)** 을 안전하게 적는 양식입니다.

---

## 2. 안 쓰면 무슨 일이 나나 (실패 사례)

- 개발자가 편하게 코드/문서에 진짜 서버 주소·접속코드를 적음 → **외부망에 내부 비밀 유출.**
- "무엇을 넣으면 무엇이 나오는지" 약속이 없어서, 내부망에 들여온 뒤 **연동이 안 맞아** 다시 개발.
- 오류 처리 약속이 없어서, 실제 연결했더니 못 보던 오류코드가 쏟아짐.

이 하네스의 게이트 `check-no-internal-secrets` 가 **실제 주소·비밀번호·개인정보 섞임을 자동 차단**합니다
(예외 승인 불가 — 보안 핵심).

---

## 3. 실제 예시로 따라가기 (메신저 사례)

`solution-card.messenger.yaml` 이 실제 사내 쪽지 시스템을 안전하게 정리한 카드입니다.

**카드에 담은 것 (외부망에 둬도 되는 "약속")**
- 기능: `send_memo` (직원에게 쪽지 발송, 최대 50명)
- 파라미터: SRV_CODE / RECIPIENT / SEND / TITLE / BODY / SAVEOPTION / SENDER_ALIAS — 길이·필수여부
- 오류코드 10개 (0·32~38·48·64) + 재시도 정책
- 특수문자 치환·개행 처리 규칙

**카드에서 일부러 뺀 것 (🔴 내부망에서만)**
- 실제 HOST/IP, 서비스 경로, SRV_CODE 실제 값, 실제 직원번호

```bash
gates/check-no-internal-secrets.sh solution-card.messenger.yaml   # 실제 비밀 섞였는지
gates/check-contract-complete.sh   solution-card.messenger.yaml   # 카드 빈칸 검사
```

→ 이 카드만 보면 외부망 개발자가 **Mock으로 코드를 다 짤 수 있고**,
실제 주소·코드는 config-secret 하네스로 내부망에서 주입합니다.

## 4. 내가 직접 할 일 vs 자동으로 되는 일

| 구분 | 누가 | 무엇을 |
|---|---|---|
| 🟡 직접 | 당신/담당자 | 내부 시스템 1개당 카드 1장 작성 (기능·파라미터·오류) |
| 🔴 내부망 | 내부 담당자 | 실제 주소·코드는 내부망에서만 (config-secret로 주입) |
| 🟢 자동 | 게이트 | 실제 비밀 섞임·카드 빈칸 자동 검사 |
| 🟢 자동 | 스키마 | 카드 형식 자동 검사 |

> 핵심: 당신은 **"메뉴판(약속)"** 만 적습니다. 진짜 주방 연결은 내부망 몫이고,
> 비밀이 섞이면 게이트가 차단합니다.

## 5. 자주 막히는 곳 (FAQ)

**Q. 어디까지 적어도 되고 어디부터 안 되나요?**
A. "무엇을 넣으면 무엇이 나온다"(기능·필드·오류)는 OK. 실제 주소·IP·접속코드·비밀번호·
직원번호·고객정보는 금지. SAFE-OR-NOT.md 에 표로 정리돼 있습니다.

**Q. 실수로 진짜 주소를 적으면요?**
A. `check-no-internal-secrets` 게이트가 IP·URL·비밀번호·주민번호 패턴을 잡아 반입을 막습니다.
이 게이트는 예외 승인으로도 우회 불가입니다.

**Q. 카드 1장은 무슨 단위인가요?**
A. "내부 시스템 1개" 단위입니다. 쪽지 시스템 1장, 내부 결제 API 1장처럼요.

**Q. 실제 연결은 언제 붙나요?**
A. 내부망 반입 후. 빈 자리(HOST·SRV_CODE)는 config-secret 하네스가 주입합니다.
