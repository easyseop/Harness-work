# policy-profile 하네스 매뉴얼 (처음 보는 사람용)

> 모르는 용어는 `core/GLOSSARY.md`(용어풀이)를 함께 보세요.
> 이 문서 하나로 이 하네스가 왜 있고 무엇을 하는지 알 수 있게 썼습니다.

---

## 1. 이 하네스가 왜 있나 (비유로)

집을 짓기 전에 **"여기에 무슨 건물을 지을 건지, 어떤 자재를 써도 되는지"** 를 먼저 정합니다.
땅 종류(주거/상업)와 허용 자재를 안 정하고 그냥 지으면, 다 짓고 나서 "이 자재는 못 쓴다"며
허물게 됩니다.

이 하네스는 개발을 시작하기 **전에** 두 가지를 못 박습니다.

- **분류**: 이게 뭔지 (배치인가 API인가, 내부 시스템을 쓰는가, 어디에 올리는가)
- **허용 범위**: 우리가 뭘 써도 되는지 (언어·프레임워크·라이선스·반입 방식)

가장 먼저 도는 하네스라서, 여기 결과(profile)를 뒤의 모든 하네스가 받아 씁니다.

---

## 2. 안 쓰면 무슨 일이 나나 (실패 사례)

- 외부망에서 최신 프레임워크로 신나게 개발 → 내부망엔 그 프레임워크가 **허용 안 됨**
  → 다 갈아엎어야 함.
- AGPL 같은 **금지 라이선스** 라이브러리를 썼다가 반입 직전에 걸림 → 통째로 교체.
- "이게 배치인지 API인지" 분류가 비어 있어서, 뒤 하네스들이 **어떤 규칙을 적용할지 몰라** 멈춤.

이 하네스의 게이트가 위를 **개발 시작 전에** 잡아 줍니다.

---

## 3. 실제 예시로 따라가기

`profile.example.json` 에 "프로젝트 1건"을 분류한 결과가 들어 있습니다 (야간 배치 잔액집계 모듈).
대략 이런 모양입니다.

| 분류 축 | 값 | 뜻 |
|---|---|---|
| 업무 유형 | 배치 | 야간에 도는 집계 프로그램 |
| 시스템 관계 | 계약만_사용 | 내부 시스템엔 약속(계약)으로만 연결 |
| 실행 환경 | 온프레미스 | 은행 내부 서버에 올림 |
| 언어/프레임워크 | java-21 / spring-boot-3 | 허용목록 안의 스택 |

이 결과가 `allowed_tech_stack`(policy.yaml의 허용목록) 안에 드는지 게이트가 검사합니다.

```bash
gates/check-classification-complete.sh profile.example.json   # 분류 빈칸 검사
gates/check-allowed-tech-stack.sh      profile.example.json   # 허용 스택인지 검사
```

## 4. 내가 직접 할 일 vs 자동으로 되는 일

| 구분 | 누가 | 무엇을 |
|---|---|---|
| 🟡 직접 | 당신/담당자 | `policy.yaml` 의 `TBD` 를 실제 허용목록으로 채우기 |
| 🟡 직접 | 개발자/담당자 | 프로젝트 1건의 분류 결과(profile) 작성 |
| 🟢 자동 | 게이트 | 분류 빈칸·허용목록 위반 자동 검사 |
| 🟢 자동 | 스키마 | profile 형식 자동 검사 |

> 핵심: 당신이 채우는 건 **"우리 조직 허용목록(policy.yaml)"** 뿐입니다.
> 비밀정보가 아니라 "자바 21 허용" 같은 **정책 사실**만 적습니다.

## 5. 자주 막히는 곳 (FAQ)

**Q. policy.yaml 에 뭘 적나요? 비밀인가요?**
A. 비밀 아닙니다. "우리가 허용/금지하는 규칙"(언어·프레임워크·라이선스·반입방식)만 적습니다.
실제 IP·URL·접속코드·직원ID는 절대 안 적습니다(SAFE-OR-NOT.md 참고).

**Q. 분류(profile)와 정책(policy)이 헷갈려요.**
A. policy = "조직 전체 허용목록"(공용, 한 번 정함). profile = "프로젝트 1건 분류 결과"(건마다 만듦).
profile 이 policy 안에 드는지 게이트가 검사합니다.

**Q. 분류가 비어 있으면 우회할 수 있나요?**
A. 없습니다. `check-classification-complete` 는 예외 승인(waiver) 불가로 설정돼 있습니다.
분류는 모든 것의 기준이라 비면 안 됩니다.

**Q. pyyaml/python 오류가 납니다.**
A. `pip install pyyaml` 후 다시 실행하세요.
