# data-standard 채우기 키트

MVP 하네스 **data-standard**(데이터 표준)를 완성하기 위한 키트입니다.
모르는 용어는 `GLOSSARY.md`(용어풀이)를 보세요.

## 이 하네스가 하는 일 (한 줄)

> 새 테이블·데이터셋·파이프라인을 만들 때, **개발하는 순간에** 이름·메타데이터·데이터 계약·흐름이
> 표준을 따르도록 강제한다. (다 만든 뒤 검사하는 게 아니라, 만드는 중에 잡는다)

## 왜 필요한가 (쉽게)

데이터는 "다 만든 다음에" 표준을 맞추려 하면 이미 늦습니다 — 테이블명·컬럼명이 굳어 버려서
DDL·API·파이프라인을 다 고쳐야 하죠. 그래서 **만드는 시점에** 이름 규칙·표준 용어·등급·흐름을
미리 못 박습니다. 나중에 흔들려서 다시 고치는 일을 줄이는 게 목적입니다.
