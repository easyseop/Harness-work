# data-standard 하네스 매뉴얼 (처음 보는 사람용)

> 모르는 용어는 `core/GLOSSARY.md`(용어풀이)를 함께 보세요.

---

## 1. 이 하네스가 왜 있나 (비유로)

새 테이블·데이터셋·파이프라인을 만들 때, 이름·등급·흐름을 **만드는 순간에** 표준에 맞춥니다.

비유하자면, **도서관에 책을 꽂기 전에 청구기호를 붙이는 것**과 같습니다.
책(데이터)을 아무 데나 꽂아 두고 나중에 정리하려면, 이미 여기저기 흩어져서 다 찾아 옮겨야 합니다.
들어올 때 규칙대로 이름표를 붙이면, 나중에 누구나 같은 규칙으로 찾고 연결할 수 있습니다.

이 하네스는 데이터의 **이름·메타데이터·계약·흐름(lineage)** 이 표준을 따르게 강제합니다.

---

## 2. 안 쓰면 무슨 일이 나나 (실패 사례)

- 테이블명이 `DepositBalance`, `deposit_bal`, `dpst_balance` 처럼 사람마다 제각각
  → 같은 데이터인데 못 찾고, 중복으로 또 만듦.
- 등급(공개/내부/민감)을 안 정해서, 민감 데이터가 아무나 보는 곳에 노출.
- 흐름(어디서 와서 어디로 가는지)을 안 적어서, 원천이 바뀔 때 **영향 범위를 몰라** 장애.

데이터는 한 번 굳으면 DDL·API·파이프라인을 다 고쳐야 해서, **만드는 시점에** 잡는 게 핵심입니다.

## 3. 실제 예시로 따라가기

`data-contract.example.yaml` 에 예금 잔액 집계 테이블이 들어 있습니다.

| 항목 | 값 | 뜻 |
|---|---|---|
| 테이블명 | `deposit_balance_daily` | 소문자_스네이크 규칙 통과 |
| 컬럼 | `stat_date` / `account_id` / `balance_amt` | 기술 이름 |
| 표준 용어 | 기준일자 / 계좌식별자 / 잔액 | 업무 표준 용어와 연결 |
| 등급 | 내부 | 허용목록 안의 등급 |
| 흐름 | inputs/outputs | 어디서 와서 누가 쓰는지 |

```bash
gates/check-naming.sh            data-contract.example.yaml   # 이름 규칙 검사
gates/check-metadata-complete.sh data-contract.example.yaml   # 메타데이터·등급·흐름 검사
```

핵심은 `name`(기술 이름)과 `standard_term`(업무 표준 용어)을 **나눠 적는 것** —
"용어는 같은데 컬럼명이 제각각"인 문제를 막아 줍니다.

## 4. 내가 직접 할 일 vs 자동으로 되는 일

| 구분 | 누가 | 무엇을 |
|---|---|---|
| 🟡 직접 | 당신/담당자 | `policy.yaml` 의 이름 규칙·필수 메타데이터·허용 등급 정하기 |
| 🟡 직접 | 개발자/담당자 | 데이터 1개당 계약(data-contract) 1장 작성 |
| 🟢 자동 | 게이트 | 이름 규칙·등급·흐름 빈칸 자동 검사 |
| 🟢 자동 | 스키마 | 계약 형식 자동 검사 |

> 핵심: 여기 적는 건 데이터의 **설계도**(이름·형식·등급·흐름)이지 **내용**(실제 계좌·잔액)이 아닙니다.
> 실제 데이터 값은 절대 적지 않습니다.

## 5. 자주 막히는 곳 (FAQ)

**Q. 실제 데이터 값(예: 계좌번호·잔액)을 예시로 적어도 되나요?**
A. 안 됩니다. 설명·예시에도 실제 값 금지. "설계도"만 적습니다(SAFE-OR-NOT.md 참고).

**Q. 우리 조직은 테이블 접두사 `tb_` 가 필수인데요.**
A. `policy.yaml` 의 `naming` 규칙(정규식)을 고치면 됩니다. 기본값은 소문자_스네이크입니다.

**Q. lineage(흐름)는 꼭 적어야 하나요?**
A. `policy.yaml` 의 `require_lineage` 가 켜져 있으면 입력/출력 중 최소 하나는 필요합니다.
원천 변경 시 영향 범위를 알기 위해서입니다.

**Q. 데이터 분석/모델링 경험만 있어도 채울 수 있나요?**
A. 네. 테이블·컬럼·자료형·등급은 익숙한 개념이고, 새로 신경 쓸 건 "표준 용어 연결"과
"흐름 적기" 정도입니다.
