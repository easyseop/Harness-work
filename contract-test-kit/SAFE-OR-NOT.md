# 안전수칙 (SAFE-OR-NOT) — contract-test

테스트는 "값"을 다루므로, 테스트 데이터에 실제 민감정보가 섞이지 않게 조심합니다.

---

## ✅ 적어도 되는 것

- 가짜 입력값 (`z000001` 같은 더미 직원번호, `ZTEST1` 같은 더미 코드)
- 기대 결과 코드 (`"0"`, `"34"` 등 — 카드에 적힌 약속)
- 케이스 설명

---

## ❌ 적으면 안 되는 것

- 실제 직원번호·고객정보·계좌번호
- 실제 SRV_CODE·HOST·IP·비밀번호
- 주민등록번호·카드번호 등 개인정보

> 핵심: 테스트는 "약속대로 동작하는지"만 보면 됩니다. 가짜 값으로 충분합니다.
> 실제 값을 넣을 이유가 전혀 없습니다.

## 게이트가 지켜 줍니다

- `check-contract-coverage` 는 테스트 데이터에 IP·주민번호 형식이 보이면 실패시킵니다.
- 외부망 테스트는 대역(Mock)으로만 — 실제 내부 시스템 호출 금지(policy.yaml).
